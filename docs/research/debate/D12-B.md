# D12-B: Against "Manim is a first-class scene renderer with LLM-authored source in a sandbox"

## Thesis
Keep ONE renderer: HTML/SVG/CSS through the virtual-clock capture tool (Task 10). Treat Manim as optional, human-made, pre-rendered clips. Making Manim first-class means running LLM-written Python on the owner's PC, on an OS where cheap isolation is weak. That risk buys little that SVG plus GSAP cannot already draw.

## Arguments
1. **Untrusted code on Windows 11 Home has no good sandbox.** The user's OS is Home (session environment). Windows Sandbox is not supported on Home (https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-overview). Job objects limit processes and resources, not sockets (https://chromium.googlesource.com/chromium/src/+show/lkgr/docs/design/sandbox.md). Blocking outbound traffic needs firewall rules for a dedicated low-privilege user, and those need elevation (https://codex.danielvaughan.com/2026/05/14/codex-cli-windows-sandbox-engineering-restricted-tokens-acls-elevated-architecture/). Plan.md Task 11a only says "no network" and gives no mechanism (addendum section 5, patch 4). WSL/Docker would add a VM on a PC with a 4 GB card; UNVERIFIED RAM headroom.
2. **The "AST allowlist" fallback is not a boundary.** RestrictedPython has repeated escapes (CVE-2026-76825, CVE-2023-37271, CVE-2023-41039: https://advisories.gitlab.com/pypi/restrictedpython/CVE-2026-76825/). A CTF write-up bypasses an AST filter with look-alike identifiers (https://b4bop4.notion.site/HKCERT-CTF-2023-Secure-Python-2-Pwn-ee01403c3e9c488e9844d305671d721e). The inputs are LLM outputs shaped by fetched web text, so prompt injection is a real path (R1/R2 in Plan.md already assume hostile sources).
3. **Install burden on the exact machine.** Manim needs ffmpeg and sox on PATH, and LaTeX (MiKTeX etc.) for MathTex/Tex (https://docs.manim.community/en/stable/installation/windows.html). Pycairo builds from source have failed on Windows (https://lightrun.com/answers/3b1b-manim-manimlib-installation-error-on-windows, older 3b1b issue). The addendum itself lists Manim-on-Windows as unverified (section 6) and makes it Spike E with "drop to HTML scenes only" as the fallback (section 5, patch 10). The plan already expects the fallback may be needed, so a first-class renderer is premature.
4. **Two renderers double the surface.** G2 and G3 (word-synced reveals, pixel QA) are solved once for the virtual-clock HTML path (addendum section 3). A Manim path needs its own cue injection, its own repair loop and its own ffprobe gates (Task 11b). Task 10 already exists to render any HTML, "not only Anatomy" (addendum section 4). Every extra renderer adds LLM repair spend to a budget the addendum says already breaches the $1.50 per-run cap (section 3).
5. **Policy risk is unchanged or worse.** Mass-templated visuals are R1. A signature Manim look generated daily is still templated. Human-curated clips support "distinct identity" better.

## Strongest point FOR, and my answer
Manim is purpose-built for algorithm, graph and math animation and has an existing Claude skill (addendum section 2). Answer: that argues for Manim as a tool, not for unsandboxed LLM execution in the daily loop. Pre-render a small library offline, human-reviewed, like the Anatomy figures (Task 10, D4). HTML/SVG plus GSAP covers graphs, arrays and flows. Pre-made Manim clips remain allowed.

## What would change my mind
- A Spike E pass on this Windows 11 Home PC: install, 5 s render in acceptable time, MathTex working.
- A demonstrated network-deny plus filesystem-confined runner that does not need elevation, or a verified WSL2/Docker setup that fits the RAM budget.
- Evidence that Sonnet-authored SVG/GSAP scenes fail visual QA on a measured class of scenes (for example, over 30% of algorithm scenes) that Manim passes.

## Scores for my alternative (HTML/SVG single renderer + offline human Manim clips), 5 = best
- Cost: 4
- Output quality: 3 (weaker on math typesetting; fine for explainers)
- Policy risk: 4
- Implementation effort (5 = easiest): 4
- Maintainability: 4

UNVERIFIED: Manim MIT licence; Home-edition WSL2/Docker performance; whether Windows Defender Firewall per-process rules suffice without admin.
